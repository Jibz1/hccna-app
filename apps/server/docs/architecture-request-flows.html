Key difference: REST uses Effect HttpApi directly; GraphQL exposes a request-scoped ctx.effect bridge.
Result path: typed service failures are translated at the transport boundary into stable GraphQL errors or HTTP responses; defects are captured by Sentry and structured logs.
Scoped lifecycleServers and Statsig are acquired once and released in reverse order.
